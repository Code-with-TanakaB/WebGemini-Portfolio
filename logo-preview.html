Usage Guidelines

✓ Best Practices

  • • Use SVG format for scalability
  • • Maintain aspect ratio when resizing
  • • Use monochrome versions for single-color printing
  • • Ensure adequate clear space around logo
  • • Test legibility at small sizes (favicon)

✗ Avoid

  • • Stretching or distorting the logo
  • • Changing the color palette arbitrarily
  • • Adding drop shadows or effects
  • • Rotating or skewing the design
  • • Using below 32x32 pixels
